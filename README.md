# Burp Tab Lock

​		一款能锁定标签页的插件，设计初衷就是为了解决Bp标签页拖出后关闭窗口标签页消失的问题，阻止标签被误拖出或重排，带中文控制页和实时命中计数。

## 安装

1. 在 Extensions > Installed 中卸载旧的 Tab Lock。
2. 添加 Java 扩展，选择 `burp-tab-lock-3.0.jar` 文件。
3. 打开顶部 **Tab Lock** 页，确认显示 **Tab Lock — 标签防误拖**。

如果旧版的状态异常残留，可在卸载旧版后重启 Burp，再加载 3.0。

## 功能说明

- **一键开关**：默认开启，阻止标签误拖出窗口或重排；关闭后立即恢复拖动。
- **自动识别**：自动保护标准标签栏，保留单击切换和右键菜单。
- **手动选取**：未自动识别时，点击“选取 / 添加标签栏”，再单击目标标签标题；支持添加多行，也可取消或清除选取。
- **实时计数**：显示标签按下命中次数和已拦截拖动次数，方便确认是否生效。

手动模式保护选中标题所在的整行，该行其他拖动也会受影响。选取仅在本次加载期间有效，布局变化后需重新选取。

## 构建和验证

需要 JDK 17，默认路径配置在 `build.ps1`。运行：

```powershell
.\build.ps1
```

使用官方 Montoya API 2026.7 作为编译依赖，不将 API 打包进插件。产物只包含插件类。

自动检查涵盖：非鼠标事件穿插、外层容器来源、普通切换、右键、内容拖动、开启/关闭、兼容行选取/取消/清除、卸载透传，以及真正 push 到 Swing 系统 EventQueue 后的事件流。

**验证边界：** 已在本机 JDK 17 下通过自动检查，尚未在用户的 Burp Professional 2026.10 中实测。Burp 没有通过本插件使用的 API 提供官方标签锁定开关，本实现依赖 AWT/Swing 鼠标事件；这不等同于所有 Burp 版本兼容性已验证。
